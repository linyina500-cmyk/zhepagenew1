# 本机贴图同步服务

服务连接折页预览网页与平台。公众号使用官方接口，支持多个账号分别保存贴图草稿、立即发表和读取结果；小红书使用本机专用浏览器完成原生草稿操作。用户操作步骤见 [Mac 本机使用说明](本机使用说明.md)，功能和验证边界见 [贴图同步说明](../../DRAFT_SYNC.md)。

## 当前部署方式

折页固定预览网页 → 当前电脑的本机服务 → 微信官方接口或小红书专用浏览器。配对是 `POST http://127.0.0.1:8789/pair`，平台 API 是 `http://127.0.0.1:8788/api/...`。两端口只监听数字回环地址；严格校验 Host 和浏览器 Origin，只有 `https://feature-local-draft-sync.zhepagenew.pages.dev` 获得 CORS 响应。API 还验证 Bearer，配对要求带随机挑战的 JSON POST，不允许简单表单或无来源请求取得凭据。不会将凭据放进 URL，不跟随重定向、不自动重试写操作。

同步推荐本机 Chrome。Safari/WebKit 会阻止 HTTPS 页面访问 HTTP 回环服务，页面会提前显示改用 Chrome 的提示，不提供绕过浏览器安全策略的替代链路。Chrome 首次连接可能询问本机访问权限，用户选择允许。权限拒绝、助手未运行和超时均在网页显示帮助，不会弹出浏览器错误页。固定本机地址不随系统重启、宽带变化而变化；不依赖 Cloudflare Tunnel、云端同步代理或维护者更新环境变量。网页继续由 Pages 提供。

Mac 仍需开机、联网且不休眠。公众号白名单应填写本机访问微信的真实公网出口 IP；出口 IP 变化是独立的平台限制。遇到 `40164`，按程序严格解析出的官方 IPv4 提示核对白名单。

## 本机准备

需要 Node.js 22.18+（22.x）或 24+，以及小红书使用的 Playwright Chromium 浏览器。首次由维护者准备依赖和本机配置；配置不含公众号 AppID 或 AppSecret。

双击 **折页同步助手.command** 会在当前用户的 `~/Library/LaunchAgents/` 安装仅含路径的启动描述，随用户登录启动。`RunAtLoad=true`，`KeepAlive.SuccessfulExit=false`，异常退出后由系统节流恢复；正常停止不自动拉起。控制操作互斥，不会因重复双击而重启运行中的任务。需要停止或停用自动启动时使用对应入口，忙碌或状态未知时拒绝中断，不强杀任务。停止成功后，下次登录仍会自动运行；停用则移除登录启动描述，保留资料。

| 配置 | 用途 |
| --- | --- |
| `WECHAT_SYNC_TOKEN` | 32–256 位独立随机连接口令，不是公众号 AppSecret。 |
| `WECHAT_DATA_DIR` | 持久任务目录，重启与升级时保留。 |
| `WECHAT_PORT` | 本机默认 `8788`。监听地址固定为 `127.0.0.1`。 |

配置在 `.wechat-sync-local/config.env`，任务在 `.wechat-sync-local/jobs/`，受控日志在 `.wechat-sync-local/assistant.log`。私有目录权限700，配置和日志600；日志记录时间与退出信号，但不输出子进程原始日志、AppSecret或设备口令。同一目录只运行一个服务实例，不要删除任务目录或复制并行运行的副本。

## 账号与凭据

公众号资料在网页首次添加，以后勾选目标账号。小红书在本机专用浏览器扫码后核对账号。AppSecret 和设备口令只在当前浏览器、当前网站的独立加密资料库持久保存，不进入海报存档或跨设备同步。

运行时凭据从浏览器经本机回环接口进入服务内存，不经过 Cloudflare 或其他中转服务，不写入本机配置、日志或任务文件。助手重启后，页面在操作时重新连接已保存账号。加密不防止同源恶意脚本或整份浏览器资料被复制。

账号名称由用户填写，请核对名称与 AppID。连接检查验证凭据与草稿读取权限，立即发表另需官方发表权限。账号的任务和回执按 AppID 派生标识隔离，执行任务时禁止断开或替换会话。

## 草稿与发表记录

公众号只使用 `newspic` 贴图：PNG/JPEG、最多 20 张、单图 10,000,000 字节、总图 60 MiB。工具标题上限 20 字，配文上限 1,000 字且不超过 2,048 UTF-8 字节。

在同步弹窗选择平台后，浏览器将图片等比适配为工具默认尺寸：小红书 1080×1440，公众号 1080×1350；完整保留内容，空余处白色留边，不改变存档中的原图。这是工具默认画幅，不表示平台强制尺寸。两个平台分别确认图片与风险提示，确认风险提示后只重绘原来的最后一张，正文、装饰和原页数保持不变；空间不足会提示调整，避免截字。上传使用已确认预览的同一份图片字节，服务端不再裁剪或转码。超长标题直接在编辑栏提示，文案不自动截断。

“已保存”要求官方草稿详情中的类型、标题、配文和全部图片素材编号顺序一致；图片实际显示另由用户核对。网页立即发布入口已关闭，原发布实现保留，由 `lib/wechat/features.ts` 控制；历史发表结果仍可查询。若将来恢复，发表前再次读取官方草稿，内容不匹配就停止，受理与发表成功分开显示。当前同步后应在公众号后台检查封面；若被裁切，重新选择封面并确认、保存后再发布。

创建和发表之前先持久保存任务阶段。已有编号不会重放，即使网络回执丢失、进程重启或结果未知。查询只使用原有草稿或发表任务编号。磁盘故障时保留当前进程已知编号，并提示先修复存储；尚未落盘的编号无法保证断电后保留。服务不会擅自删除已上传素材。

没有群发或定时接口。当前官方公开 `freepublish/submit` 只接受草稿编号，没有托管定时字段；需要定时时由用户自行到公众号后台操作。[官方发表文档](https://developers.weixin.qq.com/doc/service/api/public/api_freepublish_submit.html)

## 验证记录

本轮已用真实公众号保存两张 1080 × 1440 PNG 贴图，官方素材回读像素一致，用户已看到草稿。立即发表只完成模拟回归，没有真实发表；小红书新本机浏览器链路尚未完成真实保存与回读验收。账号隔离、凭据不落任务磁盘、明确发表确认、并发、中断、持久化故障及本机来源校验均有自动化回归。

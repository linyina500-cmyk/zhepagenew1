# 公众号草稿同步：Mac 本机版

这台 Mac 负责连接公众号官方接口，Cloudflare Tunnel 负责让折页网页连接到本机服务。电脑需要保持开机、联网并运行服务和 Tunnel；关机、休眠或关闭服务后，网页就无法同步。这里只创建贴图草稿，不会公开发布。

## 首次配置

1. 双击本文件夹中的 **配置公众号.command**，在打开的终端窗口依次填写公众号 AppID、AppSecret 和公众号名称。AppSecret 输入时不会显示字符，正常输入后按回车即可。
2. 配置保存在项目根目录的 **.wechat-sync-local/config.env**。窗口会显示完整位置。在 Finder 按 `Command+Shift+G`，粘贴该位置，可找到文件。
3. 在本机打开文件，复制 `WECHAT_SYNC_TOKEN=` 后面的连接口令，稍后填入折页网页的 **公众号连接口令**。不要把此文件、AppSecret 或连接口令上传或发到聊天中。
4. 把这台 Mac 当前网络对外访问使用的公网 IP 加入公众号的接口 IP 白名单。宽带重新连接、切换网络或 VPN 后，公网 IP 可能改变，需要更新白名单。

程序需要 Node.js 24，或 22.18 以上的 22 版。入口会自动寻找已安装的 Node.js，不会自动安装软件。

还需要免费的 Cloudflare Tunnel 程序 `cloudflared`。使用 Homebrew 时安装命令为 `brew install cloudflared`；启动入口也能使用本项目 `.wechat-sync-local/bin/cloudflared` 中已核验的官方程序。无需购买服务器。临时隧道用于测试；地址每次启动重新生成。

如果检查连接提示微信错误 `40164`，页面会在能识别时显示微信实际看到的出口 IPv4，请将它加入公众号白名单后重新检查。不要把 Tunnel 域名或 Cloudflare 网站 IP 填进微信白名单。

## 日常使用

1. 双击 **启动公众号.command**，它会启动本机服务和 Cloudflare Tunnel；保持打开的窗口。
2. 首次使用时，需要把窗口显示的临时 HTTPS 地址接入折页预览网页。临时地址在重启后可能改变，需要更新网页连接配置；出现地址不代表网页已接通。完成接入后再打开对应的折页预览网页。
3. 在折页中确认海报与文案，选择公众号，填写连接口令，点击 **检查公众号连接**，核对目标名称和账号标识。
4. 点击 **同步到公众号草稿箱**。完成后打开公众号草稿箱，确认每张海报显示正常、顺序和配文完整。

服务固定监听 `127.0.0.1:8788`。关闭终端窗口或按 `Control+C` 可停止服务，不会设置开机自启动。若同步途中关闭窗口，之后请先读取原任务状态并检查草稿箱，避免重复创建。

## 重新配置与文件保管

再次双击配置入口时，默认只显示文件位置，不读取或覆盖原凭据。明确输入 `1` 才重新填写；重配会生成新的连接口令，需在折页的公众号面板使用新口令。Tunnel 不需要公众号密钥或连接口令。已有草稿任务记录不会删除。

配置目录仅当前用户可访问（权限 `700`），配置文件仅当前用户可读写（权限 `600`）。任务记录保存在同目录的 `jobs` 文件夹。请保留这些文件，以便中断后读取结果；不要放入共享或公开同步文件夹。

# 旧本机助手：开发维护说明

网页同步已改用纯 Chrome 插件，普通用户不需要启动本机助手，也不需要安装电脑程序。Windows 和 Mac 使用相同的插件 ZIP，在网页下载并按折叠指引加载后，点击 **检测插件**。用户操作说明见仓库 [README](../../README.md)。

本文件仅保留旧助手的维护方法，用于开发排查和核对历史草稿。原有账号资料与任务记录不会自动迁移到插件。

## 维护旧助手

- 仓库中的 Mac 入口为 **折页同步助手.command**；停止使用 **停止折页同步助手.command**，停用登录启动使用 **停用折页自动启动.command**。
- 此前的独立安装包使用 **启动折页同步助手**、**停止折页同步助手** 和 **查看助手状态**。Windows 运行时需要保留助手窗口；Mac 在后台运行，随登录启动。
- 同步任务未完成时先等待结果，再停止助手。中途断网或关机后，先读取原任务并核对平台草稿，避免重复创建。
- 历史小红书草稿在原助手的专用浏览器中，应保留原资料目录。公众号草稿可直接前往公众号后台核对。

资料目录及仓库开发目录的区别见 [README：旧本机助手的开发维护](../../README.md#旧本机助手的开发维护)，服务配置见 [服务说明](README.md)。

## 历史验证边界

旧助手已完成公众号真实 PNG 草稿保存及官方图片回读，也已用小红书专用测试账号完成草稿保存、重新打开后的图片与文字核对。Windows 真实平台账号同步尚未验收；旧助手的通过结果不能代替新插件的验收。

网页只保留同步到草稿箱，发布代码保留。公众号草稿的封面仍需在后台检查；若被裁切，重新选择封面，点“确认”后再“保存”，之后在后台发布或设置定时。

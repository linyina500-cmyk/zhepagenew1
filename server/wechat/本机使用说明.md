# 贴图同步：Mac 本机使用说明

这台 Mac 负责执行平台操作。使用期间保持电脑开机、联网、不休眠。助手启动后在后台运行，可以关闭启动窗口。公众号可勾选多个账号，选择“同步到草稿箱”或“立即发布”；小红书使用专用浏览器保存草稿。

## 先连接这台电脑

请使用这台 Mac 上的 Chrome。Safari 目前不支持本机同步，可继续用于编辑和导出。

1. 双击本文件夹中的 **折页同步助手.command**，等待提示助手已在后台运行，即可关闭启动窗口。
2. 打开[固定的折页预览网址](https://feature-local-draft-sync.zhepagenew.pages.dev)，进入贴图同步面板。
3. 点击 **连接这台电脑**。Chrome 如询问访问本机，请选择 **允许**；网页显示“本机连接已保存”后即可继续。

公众号和小红书共用这次连接；已连接时直接选择平台。不需要打开连接弹窗、上传文件或填写连接口令。

首次安装后，助手会随此 Mac 用户登录启动，异常退出后自动恢复。网页直接连接这台电脑，不再使用临时公网地址。当前功能仍在开发预览验收，没有自动更新正式网站。

## 添加公众号

1. 选择公众号，首次填写公众号名称、AppID、AppSecret，点击 **保存并连接公众号**。
2. 需要多个账号时，展开 **管理公众号** 继续添加。以后直接勾选本次需要操作的公众号。
3. 确保本机访问微信的实际公网出口 IP 已加入各公众号白名单。遇到 `40164` 时，按页面显示的 IP 核对；可请维护者协助处理。

账号名称由你填写，请核对名称与 AppID 的对应关系。

## 每次操作

1. 打开原来的固定预览网址，准备海报及各平台文案。助手会在登录电脑后自动启动；如之前手动停止过，双击 **折页同步助手.command** 恢复。
2. 公众号：勾选目标账号，选择 **同步到草稿箱** 或 **立即发布**。发布前会展示标题、图片数量和全部目标账号，需要确认后才执行。
3. 保存草稿后，到公众号后台检查图片显示、顺序和配文。发布后，等待微信结果；“任务已接收”还不是发表成功。
4. 小红书：点击 **打开登录窗口**，在专用浏览器扫码；回到折页点击 **我已登录**，核对账号，再点击 **同步到小红书草稿箱**。服务会重新打开草稿核对内容，核对成功才显示已保存。

没有定时按钮。如需定时，可先存草稿，再自行到公众号后台设置。多个公众号分别执行，某个账号失败不会代表其他账号没有完成；先读取各账号原记录，不要重复提交。

## 账号资料与连接

AppSecret 只在当前浏览器、当前网址的独立资料库中加密保存，不通过应用账号同步到其他设备。执行操作时，凭据从浏览器直接送入这台电脑的服务内存，不经过云端中转，也不写入本机配置文件。更换浏览器、预览网址或清除网站数据后，需要重新添加账号。加密不能防止同源恶意脚本或整份浏览器资料被复制。

助手日志保存在本机私有目录，不记录 AppSecret 或设备连接口令。

本机连接只接受上方固定预览网址，两个服务端口仅在这台电脑上可访问。连接失败时，先打开助手；若 Chrome 曾拒绝本机访问，请在网址左侧的网站设置中允许相关权限，再点击连接。

## 停止与重启

需要停止时，双击 **停止折页同步助手.command**。有同步任务时会提示先等待完成；允许停止后会等待助手安全退出，不强制中断任务。关闭启动窗口不会停止后台助手。

系统注销或重启后，助手会在登录这台 Mac 后自动恢复。取消自动启动请双击 **停用折页自动启动.command**，资料和任务记录会保留；重新打开助手可再次启用。中途断网或关机后，先读取原任务并核对平台结果；不确定的创建或发表不会自动重试。

助手重启后，网页会在操作时重新连接已保存的公众号，无需重复填写。任务目录 **.wechat-sync-local/jobs/** 应保留，删除浏览器资料不会删除平台草稿或本机任务回执。普通连接失败时先确认助手运行和 Chrome 的本机访问权限正常，不要清除账号或任务目录。

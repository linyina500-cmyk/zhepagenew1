# 贴图同步：Mac 本机使用说明

这台 Mac 负责执行平台操作。使用期间保持电脑开机、联网、不休眠，并保留启动窗口。公众号有“同步到草稿箱”和“立即发布”两个操作，可以勾选多个账号；小红书使用专用浏览器保存草稿。

## 首次准备

1. 准备 Node.js 24，或 22.18 以上的 22 版，以及 Cloudflare Tunnel 程序 `cloudflared`。小红书还需要已安装的 Playwright Chromium 浏览器。
2. 双击本文件夹中的 **配置公众号.command**。新版只生成本机连接口令及任务目录，不在终端填写 AppSecret。
3. 配置保存在项目根目录 **.wechat-sync-local/config.env**，窗口会显示完整位置。在 Finder 按 `Command+Shift+G` 可打开该路径。
4. 在本机打开配置文件，复制 `WECHAT_SYNC_TOKEN=` 后面的口令，稍后填入折页的 **本机连接口令**。不要把此文件或口令发到聊天中。
5. 双击 **启动公众号.command**，保持打开的窗口。将它显示的临时 HTTPS 地址接入折页预览环境后，再打开对应预览网址。

Quick Tunnel 每次重启会更换临时地址，需要更新预览连接配置并重新部署。它用于开发验证，目前还不是稳定的日常连接，也没有自动更新正式网站。

## 添加公众号

1. 在折页贴图同步面板展开 **连接本机并添加公众号**，填入口令，点击 **连接本机服务**。
2. 填写公众号名称、AppID、AppSecret，点击 **保存并连接公众号**。可以继续添加其他公众号。
3. 把本机调用微信的实际公网出口 IP 加入各公众号白名单。遇到 `40164` 时，按页面显示的可识别 IPv4 核对；不要填 Tunnel 域名或 Cloudflare 网站 IP。

账号密钥在当前浏览器、当前网站地址的独立资料库中加密保存，不通过应用账号同步到其他设备。连接时会通过 HTTPS 经 Cloudflare 代理和 Tunnel 到本机服务内存，程序不在云端持久保存，也不再写入新的本机配置文件。加密不等于浏览器资料无法被复制，也不能抵御同源恶意脚本。

如果已使用旧配置，可点击 **导入本机配置**，选择原来的 `config.env`。浏览器在本地解析，不整份上传；连接仍需发送其中的账号字段。迁移和连接确认成功后，再清理旧配置里的公众号凭据，保留设备口令和任务记录。导入不会自动删除旧文件。

## 每次操作

1. 启动本机服务，打开原来的折页预览网址，准备海报及各平台文案。
2. 公众号：勾选目标账号，选择 **同步到草稿箱** 或 **立即发布**。发布前会展示标题、图片数量和全部目标账号，需要确认后才执行。
3. 保存草稿后，到公众号后台检查图片显示、顺序和配文。发布后，等待微信结果；“任务已接收”还不是发表成功。
4. 小红书：打开本机专用浏览器，首次扫码登录并核对账号，再保存草稿。需要重新打开并核对成功才会显示已保存；这条新链路尚未完成真实账号验收。

没有定时按钮。如需定时，可先存草稿，再自行到公众号后台设置。多个公众号分别执行，某个账号失败不会代表其他账号没有完成；先读取各账号原记录，不要重复提交。

## 停止、重启与保管

完成后按 `Control+C` 停止。服务会等待正在处理的任务保留结果，不设开机自启动。中途断网或关闭后，先读取原任务并核对平台结果；不确定的创建或发表不会自动重试。

服务重启后，浏览器需要重新连接公众号。更换浏览器、预览网址或清除网站数据后，需要重新添加账号。任务目录 **.wechat-sync-local/jobs/** 应保留，删除浏览器资料不会删除平台草稿或本机任务回执。

重新运行配置入口默认只显示原文件位置；输入 `1` 会重配并更换设备口令，原浏览器需要重新绑定。不要为排查普通连接问题随意重配或删除任务目录。

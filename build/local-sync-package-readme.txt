折页同步助手

第一次使用（每台电脑只需连接一次）
1. 将整个 ZhepageSync 文件夹解压到固定位置，例如“文档”。不要在压缩包内直接运行，也不要只移动其中的启动文件。
2. 双击“启动折页同步助手”。不需要安装 Node，不需要填写或上传配置文件。
3. 看到“助手已启动”或“助手已在后台运行”后，回到折页网页，点击“连接这台电脑”。浏览器如询问访问本机，请允许。
4. 小红书首次需要在专用窗口扫码；公众号在网页里添加账号。两者共用这台电脑的连接。

Windows
支持 Windows 10 / 11，64 位 x64。
同步期间保持助手窗口打开。关闭后，下次同步前再次双击“启动折页同步助手”。
关闭窗口前请等待当前同步完成；需要停止时优先双击“停止折页同步助手”。

Mac
支持 Apple 芯片和 Intel Mac，自动识别芯片，无需选择。
首次打开后助手会在后台运行；下次登录 Mac 自动启动。
请保留整个文件夹在原位置。需要停止自启动时，双击“停用自动启动”。
如果系统阻止首次打开，请在“系统设置 → 隐私与安全性”中核对来源后允许此助手，再重新打开。

浏览器
在电脑上的 Chrome 或 Edge 中打开折页。小红书登录使用单独的 Chrome 窗口，请先安装 Chrome。
网址：https://feature-local-draft-sync.zhepagenew.pages.dev/

数据与安全
每台电脑独立连接。公众号账号密钥只保存在你添加账号时的浏览器和网址中。
助手仅监听这台电脑，不向其他电脑开放；它不包含你的账号、密钥、草稿或登录状态。
公众号和小红书只同步到草稿箱，请在平台后台核对后发布。
Windows：运行期间请保持电脑开机联网、助手窗口打开。
Mac：运行期间请保持电脑开机联网。

无法连接
先打开助手，再回到原来使用的浏览器和折页网址，点击连接。
助手显示端口已占用时，请勿反复打开；查看是否已有助手窗口或后台助手运行。
换电脑或浏览器后，需要重新连接并添加账号，不会自动复制另一台电脑的密钥。

版本校验
manifest.json 记录代码版本、Node 官方下载地址及校验值、Playwright 版本及完整性校验值。
发布页提供 ZIP 的 SHA256 校验文件。Node 和 Playwright 的许可证位于 runtime 与 node_modules 对应目录。
